# Hướng dẫn thêm hình ảnh Onboarding

Để màn hình GetStarted hiển thị đầy đủ, vui lòng thêm 3 hình ảnh sau vào thư mục này:

## Yêu cầu hình ảnh:

1. **onboarding1.png** (Trang 1 - Chào mừng)
   - Kích thước đề xuất: 800x800px
   - Nội dung: Hình ảnh chào mừng, thú cưng đáng yêu hoặc logo app
   - Màu nền gợi ý: #FFF3E0 (cam nhạt)

2. **onboarding2.png** (Trang 2 - Tìm kiếm)
   - Kích thước đề xuất: 800x800px
   - Nội dung: Hình ảnh về tìm kiếm, lựa chọn thú cưng
   - Màu nền gợi ý: #E3F2FD (xanh dương nhạt)

3. **onboarding3.png** (Trang 3 - Mua sắm)
   - Kích thước đề xuất: 800x800px
   - Nội dung: Hình ảnh về giao hàng, thanh toán, hỗ trợ
   - Màu nền gợi ý: #F3E5F5 (tím nhạt)

## Lưu ý:
- File phải là PNG với nền trong suốt để tốt nhất
- Nếu không có hình, app sẽ hiển thị icon pets mặc định
- Hình nên đơn giản, dễ hiểu và phù hợp với chủ đề thú cưng

## Nguồn hình miễn phí gợi ý:
- https://www.flaticon.com/ (tìm "pet", "dog", "cat")
- https://undraw.co/ (illustrations miễn phí)
- https://storyset.com/ (pet illustrations)
